# Especificações Ativas (`docs/specs/active/`)

Este diretório armazena especificações técnicas de features atualmente **em desenvolvimento ativo**.

---

## 📌 Regras para Especificações Ativas

1. **Início de Tarefa**: Ao iniciar uma nova feature ou refatoração relevante, crie aqui a sua spec detalhada (ex.: `feat-minha-funcionalidade.md`).
2. **Conteúdo**: Defina objetivo, modelo de dados, rotas afetadas, componentes UI, critérios de aceitação e riscos.
3. **Ciclo de Vida**:
   - Enquanto o código estiver sendo escrito/testado, a spec reside neste diretório com status `Em Andamento`.
   - Após implementação, validação de testes e homologação, atualize seu status para `Concluído` e mova o arquivo para `docs/specs/archive/`.
